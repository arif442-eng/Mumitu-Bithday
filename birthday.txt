MUMITU BIRTHDAY SURPRISE WEBSITE
================================

FILES
- index.html: complete responsive website.
- README.txt: these instructions.
- Optional: birthday-song.mp3: your chosen music file (not included).

PREVIEW ON YOUR PHONE/COMPUTER
1. Put index.html and (optionally) birthday-song.mp3 in the same folder.
2. Open index.html in a browser. If your phone does not open local HTML easily, upload it using the free hosting steps below.

ADD MUSIC
- Choose an MP3 you own or are allowed to use.
- Rename it exactly: birthday-song.mp3
- Put it beside index.html before uploading.
- The visitor must tap “Play music”; browsers generally block autoplay.

ADD PHOTOS
- The three frames let you preview photos from the device currently viewing the site.
- Those previews are temporary and are NOT included in the public website link.
- To permanently include photos for everyone, edit the HTML and replace each photo-slot label with an <img src="photos/photo1.jpg" ...> element, then upload those image files in a folder named photos. Keep in mind public website photos are visible to anyone with the link.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in or create an account at https://github.com/
2. Create a new public repository, e.g. mumitu-birthday.
3. Upload index.html (and birthday-song.mp3 / photo files if used) to the repository root.
4. Open repository Settings -> Pages.
5. Under “Build and deployment”, choose “Deploy from a branch”.
6. Select branch “main” and folder “/(root)”, then Save.
7. Wait a few minutes. GitHub will show a website URL similar to:
   https://YOUR-USERNAME.github.io/mumitu-birthday/
8. Open the URL on your phone to test it, then send that link to Mumitu.

NOTES
- A free public GitHub Pages site is public to anyone who has the URL; do not include private information.
- Make sure you test the music and all sections before sending.
- You can change the wording directly in index.html using any text editor.
